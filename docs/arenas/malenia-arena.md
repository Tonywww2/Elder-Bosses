# 女武神场地：圣树根部洞厅 R2

2026-09-27 更新。场地保留“浅水、巨根、白花与昏暗洞厅”，已接入黑森林概率生成、地下洞厅与地表树根入口。本轮将装饰水层替换为含水淤泥半砖，增加白花丛的数量与组合，并使用原创 16×16 材质。管理员建造命令提供手动洞厅版本。下方折叠的旧规划保留作后续战斗集成参考。

## 黑森林自然生成

结构 ID 为 `elder_bosses:malenia_arena`，默认只在 `minecraft:dark_forest` 生成。场地中心与地表入口都检查地表生物群系，地下的溶洞生物群系不会使合法黑森林位置被误判。仅新生成的区块会产生建筑，已探索区块不会补建。

默认以 **48×48 区块**划分候选区域，`separation=16`，每个区域的候选点先通过 **50% 概率**筛选，再检查黑森林、地形和入口条件。这不是每个区块或每片黑森林有 50% 概率生成；实际数量会更少。位置与旋转由世界种子确定。

自然生成版本包含 **19 个固定 NBT 分片**，总包围范围为 `73×69×87` 格。地表有苍白树根环与白花，三格宽的八段折返石阶连接南侧前厅。中央池底方块位于入口脚底下方 58 格，半砖站立面低 57.5 格；核心洞厅与手动版本布局一致。入口锚点 `surface_entry=(3,58,46)` 随结构旋转。

选址会拒绝采样范围内的水面、悬空支承、覆土不足和陡峭地形；四个入口朝向依次尝试。默认洞顶采样点至少保留三格覆土，整片采样地表高差最多 16 格，入口区最多 2 格，门外三格宽道路与门槛高差最多 1 格。树冠可以覆盖入口上方。建筑与空气清理均来自 NBT，Java 只负责选址及按区块放置。

可用以下命令定位结构，在定位点附近寻找树根入口：

```mcfunction
/locate structure elder_bosses:malenia_arena
```

数据包可覆盖以下文件调节生成，无需修改 TOML。世界生成配置修改后重启世界；只影响之后的新区块。

| 资源（相对 `data/elder_bosses/`） | 用途 |
| --- | --- |
| [`worldgen/structure_set/malenia_arena.json`](../../src/main/resources/data/elder_bosses/worldgen/structure_set/malenia_arena.json) | `spacing`、`separation`、`frequency` 与 `salt`；`frequency=0` 关闭自然生成 |
| [`tags/worldgen/biome/has_structure/malenia_arena.json`](../../src/main/resources/data/elder_bosses/tags/worldgen/biome/has_structure/malenia_arena.json) | 允许的生物群系，默认仅黑森林 |
| [`worldgen/structure/malenia_arena.json`](../../src/main/resources/data/elder_bosses/worldgen/structure/malenia_arena.json) | 覆土与高差筛选；保持 `underground_structures` 和 `terrain_adaptation=none` |

自然结构随原版区块保存，每个片段保存模板快照，后续资源重载不会改变已登记片段。管理员 `undo/enter/info` 使用手动建造记录，不用于自然结构。玩家通过下述祈愿石召唤并绑定 Boss；生成区块时不会自动刷出女武神。

## 召唤与场地绑定

下楼进入南侧前厅，找到石拱中央的**圣树祈愿石**：这是一块嵌在地面、略微发光的白色刻纹方块。**主手持一个卢恩碎片，潜行右击**，成功后消耗一个碎片，女武神出现在北侧根座前并面向场心。创造模式不消耗供品。玩家走入战斗区域后，她开始一阶段开场；留在前厅不会提前开战。

祈愿石位于 `fog_gate` 锚点正下方，默认局部坐标 `(0,5,31)`，随建筑旋转。新生成与新手动建造的洞厅都包含它；旧版已经保存的洞厅，可以在同位置的**磨制安山岩地砖**上进行相同交互，无需拆除或重新生成。只有真实结构记录或管理员建造记录指定的位置有效，搬走或另放一块祈愿石不会形成新场地。

成功召唤前会检查场地已加载、非和平难度、出生与关键锚点无阻挡、没有已有绑定。失败不扣供品；实体被其他模组取消加入时也会撤销本次占用。供品由 `elder_bosses:malenia_offerings` 物品标签控制，默认 `elder_bosses:rune_fragment`；Forge 路径为 `tags/items/malenia_offerings.json`，NeoForge 为 `tags/item/malenia_offerings.json`。

每个维度内以场地原点记录唯一 Boss UUID。区块卸载仍保留占用，重载时验证原有主人；复制同一绑定的另一个实体会被移除。完成击败演出并移除尸体后释放占用，可再次献祭挑战。手动建造的场地有绑定 Boss 时，`undo` 会拒绝撤回。普通 `/summon elder_bosses:malenia` 仍是未绑定实体，若要使用本节规则，应通过祈愿石召唤。

绑定后，目标与人数统计只包含洞厅战斗区域内的角色，排除地表和楼梯中的玩家。Boss 的移动限制在场心周围；艾奥尼亚由招式控制连续升空，锁点投影到洞厅实际碰撞面，在池中为半格高，不会误用森林或洞顶高度。玩家可以离场；默认连续 100 tick 没有有效玩家时，清除招式和持续效果，恢复一阶段待机并回到根座，原有绑定保留，再次入场即可挑战，不再消耗供品。

相关设置位于 `config/elder_bosses-common.toml` 的 `[malenia.arena]`，在绑定时读取并随实体保存：

| 设置 | 当前行为 |
| --- | --- |
| `logical_radius` | 默认 26；固定洞厅内最大采用 26 格，避免越出建筑战区 |
| `leash_grace_ticks` | 默认 100；有效玩家全部离场后等待多久重置，0 表示下一 tick 重置 |
| `unload_resets_fight` | 默认 `true`；卸载/重载后回到根座待机，仍保留该 Boss 的场地占用；`false` 沿用已有战斗状态恢复逻辑 |

和平难度会使已绑定女武神回到待机。当前实现不封锁玩家出口，不改写玩家建筑，也未启用战斗破坏与建筑恢复；相关旧规划仍保留在文末。

## 已建成的建筑

整体 **73×42×83 格**，局部范围 `X=-36..36, Y=-4..37, Z=-38..44`。战斗空间按半径 26 格制作：中心 18 格为平缓岸面与下沉半格的水池，外围不对称坡岸升高至 5 格；所有战斗地面上方保留至少 18 格碰撞净空。北侧为分叉苍白巨根、根洞与座椅，南侧连接两道石拱前厅，高处以横向根须连接洞壁。

中央水池由 **273 块 `haligtree_silt_slab[type=bottom,waterlogged=true]`** 构成，取消上方装饰水层。脚下是下半砖，站立面比完整岸面低半格，水使用原版流体、动画与生物群系颜色。池底及岸边由完整方块封闭；模板加载器会检查封闭支承并拒绝独立水块、熔岩和其他不受支持的含水方块。半砖保留正常放置、上下叠合和水桶交互。绑定女武神忽略池岸的额外寻路代价，半砖碰撞高度用于支承、寻路与技能落点。

白花由原来的每丛 4 株增至 **7、9、11 株三种模型**，每个花株精灵含主花与侧芽；株高、宽度、位置与交叉平面角度各异，再结合四向旋转形成 12 种方块外观。花带位置与战斗净空保留，花丛没有实体碰撞。

苍白圣树根、灰褐淤泥（完整方块与半砖共用）、白花与祈愿石均使用本轮原创 **16×16 PNG**，含成簇杂色、明暗色阶和细节。素材由内置 imagegen 生成后导出为原生 16×16；[提示词与源图记录](../../tools/malenia/arena/textures/PROMPTS.md)可复现导出流程。洞壁和入口继续使用原版凝灰岩、深板岩、去皮白桦与石砖。水使用原版流体渲染，没有自定义反射 shader。

创造物品栏提供 `haligtree_root`、`haligtree_silt`、`haligtree_silt_slab`、`haligtree_white_petals` 和 `haligtree_altar`。旧 `haligtree_shallow_water` 仅保留注册以兼容已有存档，不再出现在新模板与创造物品栏中。**旧洞厅不会自动改地形**；花丛模型和材质会更新，含水半砖水池需新建场地或探索新生成的区块。

几何、方块和清理空气全部保存在 **18 个固定 NBT 分片**中，每片边长不超过 32 格，另有一个只读元数据 `root`。Forge 的 `structures/arena/malenia/` 与 NeoForge 的 `structure/arena/malenia/` 内容等价，DataVersion 分别为 3465 和 3955。作者工具只在离线导出时计算建筑，游戏内只加载与放置模板。

## 管理员建造

需要权限等级 2，所有目标区块必须已经加载，操作者和其他实体应站在目标包围盒外。`origin` 是中央池底方块的坐标，池中脚底比它高半格，干燥核心岸面比它高一格。默认入口在 `+Z`，北侧座椅在 `-Z`。

```mcfunction
/elderbosses arena malenia build <x> <y> <z> [north|east|south|west]
/elderbosses arena malenia enter <x> <y> <z>
/elderbosses arena malenia info <x> <y> <z>
/elderbosses arena malenia undo <x> <y> <z>
```

`build` 放置整座洞厅，包含清理内部空间；它会替换目标范围内普通固体方块。执行前会拒绝容器等方块实体、流体、不可破坏方块、实体占用、越界、未加载区块，以及与已登记女武神场地重叠的位置。模板缺失、未知方块、非法属性、重复标记、片段重叠、坡度或净空不合格都会在写世界之前失败。

`enter` 前往入口安全点，执行前再次检查支承与玩家空间。`info` 输出旋转后的 Boss 出生坐标。建造不会自动召唤 Boss，使用前厅祈愿石可召唤并绑定。

`undo` 恢复建造前的方块，恢复文件在世界目录的 `elder_bosses_malenia_backups/<维度命名空间>/<维度路径>/` 下，文件名是原点坐标。记录先写入临时文件，再改名，之后才放置建筑；记录可跨服务器重启读取。放置异常时立即尝试恢复；恢复失败则保留记录供重试。撤回前逐方块检查当前状态，遇到建造后的额外编辑会整次拒绝，避免覆盖后续工作。此记录是管理员建筑撤回机制，不是战斗破坏/重置系统。

一次手动放置涉及约 25 万格，会占用服务器主线程一段时间，适合在测试世界或维护期间使用。世界底部和顶部需为整个建筑留出空间；例如原点 Y=64 时模板占据 Y=60..101。手动版本是一座完整洞厅，外部通往南侧前厅的道路由地图作者衔接；地表树根与折返楼梯属于自然生成版本。

## 1. 实现边界

本文件完整保留后续建筑资产的制作与接入合同，但建筑不属于当前 Boss 实装范围。当前阶段不创建或提交竞技场 `.nbt`，不实现模板加载、放置、标记解析、场地快照或恢复链路，也不执行本文件第 8 节的建筑验收。待建筑由用户提供后，再按本文件接入并验收；届时若资产设计与本文冲突，以用户提供的最终建筑和明确裁决为准，并同步回写文档。

最终竞技场建筑必须由 Minecraft 原版数据包 NBT 结构模板提供。模板决定全部地形几何、方块、空气清理区、浅水视觉层、根系背景、座椅、雾门和出口；Java 不得按高度函数、随机噪声或材料权重重新生成建筑，也不得提供绕过模板的程序生成降级路径。当前阶段同样不得为了占位而生成临时竞技场。

模板使用固定逻辑 ID `elder_bosses:arena/malenia/*`。Forge 1.20.1 资源位于 `data/elder_bosses/structures/arena/malenia/`，NeoForge 1.21.1 资源位于 `data/elder_bosses/structure/arena/malenia/`；两个版本必须装载等价的 NBT 内容。由于竞技场直径超过单个旧版结构模板的边长限制，场地拆分为带固定局部原点的多个模板片段，由根模板清单按确定顺序放置，片段之间不得依赖随机拼接。

NBT 内使用数据模式结构方块作为标记。标记名固定为 `anchor:<name>`、`part:<name>` 或 `volume:<name>`；服务端在放置前读取并校验标记，放置后移除标记方块。锚点、模板边界和片段偏移属于结构资源合同，不从 TOML 读取。数据包可以使用相同资源 ID 覆盖内置模板，但不得新增脚本、技能或任意执行逻辑。

后续接入时，Java 只负责选择固定结构 ID、旋转和放置模板、检查区块与目标空间、解析标记、建立战斗边界、记录放置前快照、维护 Boss 破坏记录以及重置恢复。破坏预算、穿墙时长和逻辑战斗半径由唯一 common 配置的 `[malenia.arena]` 控制。

局部坐标原点 `(0, 0, 0)` 是 NBT 根模板中 `anchor:arena_origin` 标记的位置。`+Z` 指向入口雾门，`-Z` 指向圣树根座椅；所有片段偏移和锚点先以该原点表达，再随根模板一起旋转到世界坐标。

## 2. 模板与几何合同

NBT 中完成的地形必须满足以下轮廓；这些数值用于资产制作与放置后校验，不用于 Java 铺设方块：

| 半径 | 基础高度 | 功能 |
| ---: | ---: | --- |
| 0-8 格 | 0 | 浅水中心、主要决斗区 |
| 8-18 格 | 从 0 线性升至 1 | 低缓坡，不中断导航 |
| 18-24 格 | 从 1 线性升至 3 | 外环坡地，提供盆地轮廓 |
| 24-26 格 | 从 3 平滑升至 5 | 根岸和场地边界 |

不规则轮廓只能由结构作者固化在 NBT 的 18-26 格区域，高度偏差不超过 1 格，且任意相邻可行走方块高差不超过 1 格。0-18 格核心战区禁止坑洞、台阶、栅栏、墙体和树根碰撞体。装饰性根须使用无碰撞模型或放在 24 格半径以外。

中心 0-8 格覆盖不超过 0.125 格的视觉浅水材质；逻辑碰撞面仍是完整方块顶面。浅水不改变移动速度，不熄灭火焰，不放大雷电，不参与寻路代价。

每个模板片段必须拥有唯一 ID、固定尺寸、相对 `arena_origin` 的整数偏移和内容版本。片段交界处不得重复放置方块实体；所有片段合并后只能存在一组必需锚点。模板可以包含实体时必须显式列入白名单，默认放置时忽略实体。

## 3. 后续放置顺序

建筑资产提供并进入接入阶段后，服务端按以下顺序放置，任一步失败都回滚本次放置：

1. 解析全部 `elder_bosses:arena/malenia/*` 模板及其标记，拒绝缺失、重复锚点、越界片段和未知标记。
2. 根据所有片段的合并包围盒检查所需区块已加载，且不覆盖不可替换方块或其他已登记竞技场。
3. 在修改世界前记录整个合并包围盒的原世界快照；NBT 中显式保存的空气负责清理目标空间。
4. 按根模板清单的固定顺序，以相同旋转和镜像策略放置全部片段；默认禁用完整性随机和随机调色板。
5. 解析并移除数据标记，建立锚点、战斗边界、受保护区域和可恢复区域。
6. 运行片段接缝、5×5 格坡度、18 格净高、导航连通、水鸟路径和俯冲落点检查；失败则恢复原世界快照。
7. 保存成功放置后的竞技场基线快照，供战斗重置恢复；模板重载只影响下一次新建竞技场。

## 4. 方块调色板与原作语汇

正式资产使用原创材料组合，不复制原作纹理。具体方块和分布由结构作者固化进 NBT，不在运行时按权重替换。默认方块可先使用原版占位，后续替换 NBT 时保持标签职责不变。

| 承重底层 | 石头、深板岩 | `arena_protected`，永不破坏 |

## 6. Boss 高差适配

- 导航目标、锁点和回场位置先取得高度图表面，再投影到最近合法站立点。
- 跑斩、突刺、水鸟和俯冲使用相对地表曲线；盆地升降只改变世界坐标 `Y`，不缩短水平距离、不降低速度、不提前结束有效段。
- 水鸟每轮路径按 0.25 格间隔采样地面，Boss 脚底保持在地表以上 1.8-2.4 格；外环 5 格高差不得造成撞地。
- Boss 在竞技场边界内免疫摔落伤害，玩家仍遵循原版摔落规则。
- 路径穿入外环装饰时先尝试破坏白名单方块，再启用最多 20 tick 的方块碰撞忽略；不得越过 26 格逻辑边界。

## 7. 破坏、穿墙与恢复

`elder_bosses:boss_breakable` 默认包含外环薄根、松散石块、装饰叶片和非承重残骸；`elder_bosses:arena_protected` 包含承重底层、逻辑边界、雾门、锚点基座和主要根岸骨架。两个标签冲突时保护标签优先。

马莲尼亚每 tick 最多破坏 24 个方块，单次作用半径默认 1.5 格。方块实体、容器、传送门和流体源默认排除。穿墙期间仍受玩家、投射物和攻击判定影响。战斗重置、胜利后清场或服务器恢复异常战斗时，按基线快照恢复被破坏方块；玩家在战斗期间放置的方块单独记录并移除，不覆盖原世界快照。

# 腐败女神竞技场：程序构造规范

> Boss ID：`elder_bosses:malenia`  
> 构造方式：服务端 Java 程序生成  
> 设计目标：圣树根部盆地、中心低而外缘高、浅水反光、核心战区无永久卡点

## 1. 实现边界

竞技场几何、方块放置、锚点验证、重置快照和破坏恢复全部由程序控制，不定义自定义竞技场数据包类型。允许使用方块标签、战利品表和结构方块等 Minecraft 既有资源类型，但默认构造器不依赖 NBT 结构模板。尺寸、高度、材料权重、破坏预算和穿墙时长由唯一 common 配置的 `[malenia.arena.*]` 子树控制。

局部坐标原点 `(0, 0, 0)` 是盆地最低处的场心地面。`+Z` 指向入口雾门，`-Z` 指向圣树根座椅；所有构造计算先在局部坐标完成，再通过竞技场朝向矩阵转换到世界坐标。

## 2. 平面与高度函数

使用水平半径 $r=\sqrt{x^2+z^2}$ 计算基础高度，最终高度取整后再叠加受限噪声：

| 半径 | 基础高度 | 功能 |
| ---: | ---: | --- |
| 0-8 格 | 0 | 浅水中心、主要决斗区 |
| 8-18 格 | 从 0 线性升至 1 | 低缓坡，不中断导航 |
| 18-24 格 | 从 1 线性升至 3 | 外环坡地，提供盆地轮廓 |
| 24-26 格 | 从 3 线性升至 5 | 根岸和场地边界 |

高度噪声只允许作用于 18-26 格区域，幅度不超过 1 格，且任意相邻可行走方块高差不超过 1 格。0-18 格核心战区禁止随机坑洞、台阶、栅栏、墙体和树根碰撞体。装饰性根须使用无碰撞模型或放在 24 格半径以外。

中心 0-8 格覆盖不超过 0.125 格的视觉浅水材质；逻辑碰撞面仍是完整方块顶面。浅水不改变移动速度，不熄灭火焰，不放大雷电，不参与寻路代价。

## 3. 构造层次

服务端按以下顺序构造，任一步失败都回滚本次放置：

1. 校验半径 32 格、向上 24 格的包围盒已加载，且不覆盖不可替换方块或其他已登记竞技场。
2. 清理半径 28 格、地面上方 20 格的可替换空间，记录原世界快照。
3. 铺设厚度 4 格的承重底层；底层全部加入 `elder_bosses:arena_protected`。
4. 按高度函数铺设盆地表面和外环根岸，验证从任意可行走点到场心存在路径。
5. 放置浅水视觉层、根系背景、座椅、雾门、出口和逻辑锚点。
6. 运行 5×5 格坡度、18 格净高、水鸟路径和俯冲落点检查；失败则回滚。
7. 保存完成后的竞技场基线快照，供战斗重置恢复。

## 4. 材料与原作语汇

正式资产使用原创材料组合，不复制原作纹理。默认方块可先使用原版占位，后续替换时保持标签职责不变。

| 层 | 默认占位材料 | 权重 | 标签与职责 |
| --- | --- | ---: | --- |
| 承重底层 | 石头、深板岩 | 70% / 30% | `arena_protected`，永不破坏 |
| 中心表面 | 方解石、平滑砂岩、浅灰混凝土粉末 | 45% / 35% / 20% | 平整、低饱和 |
| 外环坡面 | 泥土、缠根泥土、凝灰岩 | 35% / 35% / 30% | 可按白名单局部破坏 |
| 根岸骨架 | 去皮橡木、泥砖、自定义圣树根方块 | 30% / 20% / 50% | 主要骨架受保护，薄壳可破坏 |
| 浅水视觉层 | 自定义薄水面或无碰撞渲染层 | 100% | 不参与物理与寻路 |

背景以灰白根系、暗灰洞壁、枯黄叶片和少量暗金嵌件构成。第二阶段可由客户端逐步显示暗红菌丝，但不能永久替换地面或改变碰撞。

## 5. 锚点

| 锚点 | 局部坐标 | 用途 |
| --- | --- | --- |
| `arena_center` | `(0, 1, 0)` | 回场、范围计算和落点裁剪 |
| `boss_spawn` | `(0, 1, -11)` | 座椅前的休眠位置 |
| `aeonia_opening` | `(0, 8, 0)` | 第二阶段开场升空锚点 |
| `player_entry` | `(0, 1, 23)` | 玩家穿过雾门后的安全点 |
| `fog_gate` | `(0, 2, 26)` | 南侧雾门中心 |
| `exit_gate` | `(0, 2, -25)` | 战后出口中心 |

每个锚点必须拥有至少 3×4×3 格净空。`aeonia_opening` 下方 6 格半径内不得出现上表面碰撞体。入口与出口不能与水鸟直线路径重合。

## 6. Boss 高差适配

- 导航目标、锁点和回场位置先取得高度图表面，再投影到最近合法站立点。
- 跑斩、突刺、水鸟和俯冲使用相对地表曲线；盆地升降只改变世界坐标 `Y`，不缩短水平距离、不降低速度、不提前结束有效段。
- 水鸟每轮路径按 0.25 格间隔采样地面，Boss 脚底保持在地表以上 1.8-2.4 格；外环 5 格高差不得造成撞地。
- Boss 在竞技场边界内免疫摔落伤害，玩家仍遵循原版摔落规则。
- 路径穿入外环装饰时先尝试破坏白名单方块，再启用最多 20 tick 的方块碰撞忽略；不得越过 26 格逻辑边界。

## 7. 破坏、穿墙与恢复

`elder_bosses:boss_breakable` 默认包含外环薄根、松散石块、装饰叶片和非承重残骸；`elder_bosses:arena_protected` 包含承重底层、逻辑边界、雾门、锚点基座和主要根岸骨架。两个标签冲突时保护标签优先。

马莲尼亚每 tick 最多破坏 24 个方块，单次作用半径默认 1.5 格。方块实体、容器、传送门和流体源默认排除。穿墙期间仍受玩家、投射物和攻击判定影响。战斗重置、胜利后清场或服务器恢复异常战斗时，按基线快照恢复被破坏方块；玩家在战斗期间放置的方块单独记录并移除，不覆盖原世界快照。

## 8. 验收

- 盆地从中心 0 格平滑升至外缘 5 格，任意相邻可行走方块高差不超过 1 格。
- 中心 18 格内无碰撞装饰，任意点可导航至场心。
- 水鸟三轮、7 格突刺和猩红艾奥尼亚可跨越全部坡段，不撞地、不漂浮、不缩短水平距离。
- Boss 只能破坏白名单方块，不能破坏承重底层、雾门、边界和锚点。
- 穿墙期间不能离开竞技场、穿过玩家盾牌面或获得无敌。
- 战斗重置后场地与构造完成时的基线逐方块一致。

## 9. 原作资料与新增图像观察

### 9.1 可核对的位置关系

- [米凯拉的圣树](https://eldenring.wiki.gg/wiki/Miquella%27s_Haligtree)分为上层树冠聚落和下层艾布雷菲尔要塞；马莲尼亚位于圣树躯壳脚部的深处。
- [艾布雷菲尔](https://eldenring.wiki.gg/wiki/Elphael,_Brace_of_the_Haligtree)沿圣树东北侧分层建造，其城市深处通向圣树内部；下层和内部区域受到猩红腐败侵染。
- 赐福顺序包含 `Haligtree Roots` 与 `Malenia, Goddess of Rot`，说明战斗入口位于根部前厅之后，而不是城市露天平台。

以上事实只确定纵向位置、入口语汇和环境主题，不提供可直接换算成 Minecraft 格数的原作尺寸。

### 9.3 对当前构造的修正

- 盆地高差表现为“中心平缓、边缘根岸抬升”，不能做成规则阶梯碗；8-24 格坡段应以连续不对称根脊打断圆形轮廓。
- 场心表面以暗灰湿地、浅水反射和少量白色沉积为主，不使用大面积明亮方解石棋盘纹。
- 入口侧可以保留一段石拱前厅，但穿过雾门后 6 格内迅速转为根系洞窟。
- 外圈至少设置 3 个纯视觉深色凹口，制造根部空腔感；这些凹口不可形成玩家可进入的永久掩体。
- 战后花芯优先放在场心偏入口反侧 2-4 格的位置，确保从入口与场心都能清楚看见。

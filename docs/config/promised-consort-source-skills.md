# 约定之王：原作技能配置

2026-09-30。依用户最新决定，旧26个项目技能组合及4个远程变体已移除运行、配置和命名测试入口；只运行本批从原AI／HKS／TAE重建的技能。历史分类记录仅供查阅。不提供旧字段或旧配置快照兼容。

唯一配置文件为 `config/elder_bosses-common.toml`，下列字段属于 `[promised_consort.skills]`，共1820个可编辑项，内部执行参数固定保存，包含秒杀投技开关，一起捕获到当前遭遇快照。完整双语默认值见 [common示例](elder-bosses-common.example.toml)，字段类型和允许范围见 [配置定义](../../src/main/resources/assets/elder_bosses/boss/promised_consort/source_config_defaults.json)。原ID、挂点、事件数量和分身槽次是固定结构证据。Configured界面按游戏语言显示名称和说明，接入版本与阅读指南见[配置规范](README.md#configured界面与中英说明2026-10-01)。

## Boss受伤与远程判定（2026-09-30）

Boss受伤直接使用Minecraft原版结算，保留传入的DamageSource和伤害数值，由原版护甲、抗性效果、附魔、吸收生命及加载器／模组钩子处理。已移除拉塔恩的`damage_routing`、`resistance`、`source_multiplier`、`status`配置、入伤换算器、专用入伤DamageType及自定义伤害免疫清单。遭遇资格、首次参战规则和阶段无敌仍由生命周期机制控制。

`[promised_consort.targeting].ranged_damage_distance = 9.0`：受到有效伤害时，来源玩家到Boss碰撞箱的水平距离达到该值，也判为远程攻击；采用玩家当前位置，不采用命中点或投射物位置。原投射物／标签分类和投射物生成时的Shoot通知继续生效，`non_ranged`、强制死亡与被动异常伤害仍排除。新增受伤反应在实际生命损失大于0时通知原作Shoot分支，多个同tick通知合并。

下面“攻击、弹丸与效果”的攻击点数换算用于Boss攻击目标，不参与Boss受伤结算。当前配置快照只接受当前字段结构，不迁移旧入伤配置。

运行开销优化：FXR节点动作、外观、发射形状及父节点关系在资源加载时建立索引；客户端仅浅拷贝特效实例列表以排序，避免每帧深拷贝刀光历史；服务端缓存特效尾部时长，同一tick同一攻击预警只采样一次。命中范围、原事件时间与装饰粒子预算不因这些优化改变。

## 动画段

运行时包含81段，配置只公开其中47段的有效参数。

`animations.aTAE` 使用TAE身份。例如 `a20012` 的姿态来自HKX4101，两个身份不能合并。

| 字段 | 用途 |
| --- | --- |
| `windup_ticks`、`active_ticks`、`recovery_ticks` | 绝对游戏tick，20tick＝1秒，允许小数；默认值直接来自原微秒时间；原来不存在的零长度阶段固定为0 |
| `warning_lead_ticks` | 预警提前量，至少1tick |
| `target_lock_lead_ticks` | 命中前锁点提前量 |
| `targeted_landing` | 落点适配开关；3031、3032与3028固定对齐目标，其余按配置开关；目标前间距为内部基准 |
| `hyper_armor_active` | 原霸体窗口是否启用 |

时间修改后，姿态、TAE、根移动、分身召唤、抓取和预警共同使用分段映射时钟。前摇结束于原第一条攻击／发射事件，释放覆盖原窗口，余下时间为后摇；事件顺序和条件不变。晚于姿态末帧的TAE元数据保留，不通过拉长姿态制造新动作。

大荒星陨3024在最后一次分身召唤之后，按四个分身各自配置的实际落地时刻重新安排本体下降段：本体在最后一个分身落地后0.15秒触地。召唤前的配置时钟和分身的独立时钟不变，下降段连续变速；本体动画、移动、伤害、音效、特效及预警使用同一个调整后的时钟。落地后的配置播放节奏不变。未配置的原作预览保留原始时间。

开场默认目标前间距3.5格，狮子斩默认0格，重力突进默认2格。锁定后的落点不随目标后续移动改变。原Master／Root／Pelvis垂直轨迹锚定实际地面，地面修正通过整身平移保持腰、手、双刀和判定体一致。

## 攻击、弹丸与效果

`attacks.aAtkID` 提供 `flat`、`attack_ratio`、五个伤害通道数值、`knockbackDist` 和 `max_hits_per_target`；判定半径使用固定基准乘全局范围百分比。

伤害公式：

`flat + Boss当前攻击力 × (atkPhys + atkMag + atkFire + atkThun + atkDark) / 100 × attack_ratio`

默认通道值来自原AtkParam。Minecraft适配将雷电合入魔法、原Dark对应圣属性。击退距离为配置值乘0.1，负值表示牵引。每个攻击窗口按演员／事件／目标计数，同一tick不重复结算该窗口。

`projectiles.aBulletID` 提供寿命、发射数量／间隔、子弹生成间隔及每目标命中上限。角度、速度、加速度、重力、诱导和几何参数为内部基准；判定半径、高度、预警长度及射程按全局范围百分比缩放。`numShoot=0` 停止该发射；负寿命保留原无限寿命含义。弹丸与Atk两项命中上限共同约束实际命中次数。

新弹丸实际出生不早于当前处理tick的下一tick，保证至少一个服务端tick预警；这是Minecraft适配，原发射证据未改写。移动弹丸显示地面通道，静止弹丸显示地面圆形；踏地、重力牵引、米凯拉之光的发射提示覆盖后续落地伤害。纯运输辅助弹丸不逐颗画误导性的伤害提示。

状态标记的效果时长属于内部执行参数。`bleed.*` 配置阈值、衰减、每脉冲累积、持续／脉冲间隔和结算伤害；投技捕获距离和高度由全局范围百分比调整。抓取及魅惑／死亡／释放帧随对应段时间轴执行。

## 地形、神门出生与旧指示器规范

`terrain.max_step_up`、`ground_search_depth`、`max_ground_drop_per_tick`、`foot_clearance` 控制表面搜索、上台阶、每tick下落上限和脚底间距。实际移动保留Minecraft碰撞，包含半砖和台阶；不单独冻结腿部或扭曲腰部。

新结构 `boss_spawn` 为局部 `[0,5,-50]`：神门前平台比场心高4格。出生、待战、朝向和开场起点使用此建筑锚点。开场允许Boss从门前进入场内，参与者逻辑半径仍为40格。已有竞技场及绑定快照不会自动改写，验收新位置使用新生成竞技场。

范围预警复用既有IndicatorSnapshotPacket与客户端规范。近战和抓取的57个攻击段使用逐段匹配的扇形、长条或落地圆形预警；所有顶点使用同一平面高度，并可透视。颜色按物理／重力／血焰／圣光／分身分类。辅助弹丸不单独产生地面小圈，具有实际伤害的圣光柱仍显示各自的范围。`[indicators]` 的总开关、Boss开关、透明度和预算生效；瞬防脉冲次数／颜色及音效仍读取 `[promised_consort.instant_guard]`，独立于一般特效开关。

## 生效与测试命令

动作音效使用原TAE事件与本节同一分段时钟；声源采用新骨架挂点、独立分身或投射物位置。旧项目六类音色统一受`[promised_consort.nonverbal_audio].enabled/volume/pitch`控制，密集柱群共享每tick混音预算；瞬防提示仍使用独立`instant_guard.*`配置。刀路音高／音量在制作阶段取新姿态导出，运行时不计算角度或读取旧动画。

基础实体属性需重启；技能和战斗机制在开战时冻结完整快照，进行中的战斗不随热重载改变。当前保存格式为SourceCombat v12、Playback v4、SourceSkillConfig v8，只接受当前完整配置。无法读取的遭遇配置快照会结束当前战斗并回到待战状态，使用当前配置重新开战，不转换旧字段。

```text
/elderbosses test promised_consort source_animation 3010 1
/elderbosses test promised_consort source_act 5 1
/elderbosses test promised_consort source_act 20 2
```

`source_animation` 只预览姿态；`source_act` 执行真实原作动作链和伤害。完整验收项目见 [验收表](../../tools/consort/ACCEPTANCE.md)。


## 两种命中方式与地面范围（2026-09-30）

```toml
[promised_consort.skills.hit_detection]
simple_ranges = true
```

默认 `true`：玩家脚点在地面扇形、长条或圆形范围内，并满足高度限制，即参与该段命中结算；不采样刀尖或碰撞胶囊轨迹。原事件生效时间、伤害、每目标次数、抓取、弹丸生命周期及子链继续执行。移动弹丸使用当前位置的简单圆形和高度限制，不做扫掠轨迹判定。

`true` 使用逐段简单地面范围，直接命中范围内玩家；`false` 使用姿态轨迹和弹丸碰撞。两版都对同一演员段、目标共享接触免疫，覆盖双刀、窗口和派生弹体；`segment_immunity_ticks=10` 为0.5秒，进入同槽下一段提前清除。格挡和瞬防也消耗一次接触。不同分身、玩家独立计数。命中上限在免疫到期或进入下一段时重置；轨迹模式每轮上限1，简单模式使用配置上限。两版均显示大致地面预警。

57段地面范围在 `source_ground_areas.json` 定义为固定基准。主配置只有 `range_percent` 调整攻击范围：100为当前基准，150为1.5倍，50为一半；长度、宽度、前偏移、高度、刀刃胶囊及其相对身体的位置、弹丸判定与地面预警同步缩放。角度和朝向保持各招式匹配值；根移动、锁点和技能速度不随此百分比改变。

弹体的简单半径、高度和预警通道长度采用内部基准，并同步乘全局范围百分比。静止地面区采用落地高度，飞行弹体仍需要玩家处于其实际高度附近。简单模式的两个150米圣光闪光范围默认适配为20格；圣光爆发在轨迹模式也以该20格地面半径为上限，避免150米原参数覆盖整个场地。伤害数值与范围可以分别调整。

`spacing.minimum_melee_distance=3.5` 控制接近停止距离；`retreat_when_crowded=true`、`retreat_distance=4.5`、固定速度0.8控制待机时短暂退让。`retreat_ticks=12` 和 `retreat_cooldown_ticks=30` 控制每次退让时长和间隔，避免一直后退不出招。正在执行的原动作根移动、开场与狮子斩落点不被此逻辑改写。

## 特效与崩溃修复（2026-09-30）

血焰改用Minecraft火焰／烟雾贴图粒子；出血改用红石材质碎屑粒子。关闭对应原FXR绘制，不再叠加整张原作粒子图。重力采用旧版紫色能量材质，主要空间尺寸放大1.8倍并提高亮度，旧版屏幕扭曲半径由2.6增至4.7、强度增至1.5。陨石使用旧版哭泣黑曜石方块物品模型，当前默认显示尺寸1.35，采用本次run配置值，仍跟随当前原作弹体的位置、时钟和轨迹。周围重力曲面、环壁及尾迹随陨石尺寸同比缩放。

粒子在客户端tick发射，每Boss共享最多64颗且服从已有更小预算；不按渲染帧反复生成。一般特效开关、距离和预算继续来自 `skill_vfx.*`。

分身装饰特效引用的缺失挂点120改为跟随该演员身体中心；仅装饰允许该处理，攻击及弹体发射挂点仍严格检查。配置和战斗状态JSON用NBT字节数组保存，解决超过65535字节后 `UTFDataFormatException` 导致存档写入失败。只接受上列当前保存版本，不迁移旧格式。

米凯拉头顶新增连续覆盖帽层，长发增加100个随原发链运动的外层几何；仍使用原项目纹理和当前新骨骼动画。

`visuals.gravity_size_multiplier/gravity_strength_multiplier/gravity_distortion_radius/gravity_distortion_strength` 可调整重力尺寸、亮度和扭曲；`meteor_size` 调整旧陨石外观大小；`bloodflame_particles_per_tick/bleed_burst_particles` 调整贴图粒子数量。仍服从总特效预算，视觉参数不改变伤害半径。当前重力以增强的背景折射为主，本体、双刀和陨石共用特效挂点；紫色外观改为较淡的两层错位碎涡，尾迹同步降低亮度。扭曲每帧只复制一次场景，最多24个局部区域；近距离仍能显示。

圣光统一使用外层金色、内层浅白的两层方形光柱。出现时不透明度为0.5，宽度为初始值；先缓慢、后快速收窄并变透明，高度保持不变。光柱完全消失后，地面光圈以0.06不透明度出现，并用原设定一半的时间淡出。普通剑光仍使用两个阶段共用的完整灰白宽带；魅惑诅咒仍使用透明符号。

全部参数位于主配置 `[promised_consort.skills.visuals.holy_columns]`，Configured 中英标签同步更新。当前结构不保留旧圣光宽度及淡入淡出字段。参数只控制外观，命中范围、攻击时刻和伤害由技能参数控制。

# 女武神 V15：位移、投技与视觉可读性

## 当前实现

1. 延长跑斩、突刺、飞翔斩突进与水鸟前三段的移动预算。跑斩基础距离 9、突刺 10、飞翔斩 11；仍叠加各技能的距离倍率。跑斩和突刺的攻击段延长为 6 tick，位移仍按加速曲线执行并保留地形碰撞。
2. 披风收窄为连续重叠的三段布面，减小静态折角、参差下摆和过强的躯干反向摆动；保留逐段滞后与受速度、转向驱动的次级运动。
3. 停止巡航时清除导航、移动控制器输入及水平惯性；技能中的位移由执行器驱动，技能间隙继续保留正常重力。
4. 范围指示器增加深色粗描边、明亮内线与更明显的透明填充。显示边界仍取服务端实际攻击几何。
5. 左手改为掌块、四指块、拇指块；右手以掌块、两块相连的弯曲四指组与拇指组包住刀柄。抓取时由整个四指组合拢，取消可见的细指节结构。
6. 投技抓取与后续攻击绕过普通盾牌格挡，窗口内的弹反能阻止抓取。抓取后取消举盾与骑乘，10 tick 平滑抬升至脚部高于 Boss 基准面 1.9 格；服务端同步玩家位置，穿刺、释放、技能取消时恢复重力。
7. 绽放花的视觉半径扩大到原指示半径的 1.32 倍，五层共 42 片花瓣，补充上下表面和侧壁，提升橙黄亮部与花脉亮度。伤害区域依然由地面指示器标明。
8. 本体翅膀在实体动画求值后使用显式实体捕获躯干变换；改为与分身相同的骨骼轴心变换方法。每个世界渲染阶段消费当帧记录，移除实体渲染与世界渲染 `partialTick` 必须精确相等的条件，保留扩展视锥范围。
9. 弹反改用服务端技能窗口判定：默认从该段攻击前 8 tick 起，到最后一个有效攻击 tick 结束。窗口内开始使用合格盾牌即记为有效举盾，不等待原版举盾启动延迟，也不额外要求朝向或重新准备时间。红白光圈在同一窗口显示，白圈内收并伴随亮点旋转。
10. 猩红腐败改为连续横条：未发作时显示积累比例，发作时显示剩余持续比例；取消花瓣计数与数字倒计时。
11. 分身突袭末段本体冲入由 32 tick 缩短为 12 tick，整体时间轴改为 126 tick，同步调整实际位移、刀轨及动画着地与恢复时间。

## 配置

```toml
[malenia.instant_guard]
enabled = true
cue_effect_enabled = true
window_ticks = 8
blocked_damage_multiplier = 0.0
shield_durability_multiplier = 0.5
cue_pulse_count = 3
red_cue_color = "#FF2020"
eligible_item_tag = "elder_bosses:instant_guard_items"
```

`cue_effect_enabled` 只控制红白光圈；关闭它不影响弹反判定和声音。光圈独立于地面指示器、一般技能特效的显示开关。`window_ticks` 控制攻击前的有效举盾时间，不包含攻击段自身持续时间。当前配置示例见 [common TOML](../config/elder-bosses-common.example.toml)。本次不提供旧字段迁移，也不修改玩家已有配置或存档。

## 资产维护与验证

当前资产为 `combat_readability_v15`，92 根骨骼、385 个 cube、1,369 个纹理面、40 段动画。材质仍沿用 V12 像素图集。增量几何维护脚本为 `models/malenia/scripts/refine_v15.js`；动画生成后执行 `sync_animations.js`，再执行共享资产检查。

- Node 检查覆盖步态、手部动作、关节限制、攻击加速及技能节奏；共享检查核对原生工程、导出资源与运行资源的一致性。
- Java 检查覆盖窗口边界、光圈与服务端窗口一致、光圈关闭、当前配置 NBT 往返、动画时间轴和技能效果生命周期。
- 隔离 Forge GameTest 使用真实执行器与可受伤的盾牌测试玩家，验证抓取、抬升、穿刺、释放、弹反取消抓取，以及冲刺距离、幻影末段速度、待机防漂移和水鸟/绽放连续位移。
- 离屏 OpenGL 编译实际 GLSL，并渲染花朵、光圈、本体与翅膀、手部近景和披风动作。预览在 `build/malenia-v15/previews/`，日志在 `build/malenia-v15/`。

离屏渲染和服务器测试不等同于客户端实机战斗验收；本体翅膀的世界显示、多人网络下的抓取观感与披风运动仍需在游戏中确认。

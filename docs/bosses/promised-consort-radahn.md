# 约定之王当前战斗规格

实体 ID：`elder_bosses:promised_consort`。本项目显示名称为「约定之王」。
支持 Minecraft 1.20.1 Forge 与 1.21.1 NeoForge。

## 当前实现

战斗使用当前原作解包的 AI/HKS/TAE 状态链、80 个 HKX 姿态、81 个 TAE 段和 22 个技能入口。
原项目新增技能已经按用户要求移除选招和配置。技能段、动作身份与骨架挂点见
[当前技能配置](../config/promised-consort-source-skills.md)。正式战斗和命令预览使用同一模型与动画银行。

## 场地与阶段

- 祭坛献祭后，Boss 在绑定场地的神门前高坡等待玩家进入。
- 一阶段、二阶段、转场、硬直、死亡和脱战由服务端状态驱动。
- 激活后从当前站位播放开场动作，不预先传送到空中。
- 二阶段转场播放源动作 20011 向神门行走，动作结束后米凯拉出现，再以待机姿态转向场心，保留两句项目字幕。
- 大荒星陨落点固定在绑定场地中央；无绑定时使用开战中心。
- 大荒星陨默认 `cooldown_forced`，完成后等待 `consort_meteor.cooldown_ticks` 再释放，默认 1200 tick。
  `once` 为每场一次；`weighted` 为冷却后按权重选招。技能进行期间不重复触发。
- 死亡演出完成后走原版实体战利品流程，并释放场地绑定。

## 命中和移动

默认使用简单范围命中；主配置 `promised_consort.skills.hit_detection.simple_ranges=false` 切换为源姿态轨迹。
两种模式对同一演员段与目标共享接触免疫，默认0.5秒，进入同槽下一段提前清除；轨迹模式每轮最多一次接触。双刀、多个窗口与派生弹体共享记录，不同分身独立记录。
地面预警按技能段匹配范围，与刀光分开绘制。普通剑轨迹统一为宽灰白色。

Master、身体 Root、Pelvis 的身体升降完整保留；源挂点驱动双刀、分身、投射物和音效位置。
服务端处理根路径和地形锚点，客户端避免重复应用 Master 平移。
动作结束当tick释放已完成的播放状态并切入下一段或源待机，复位未驱动通道，不使用通用骨骼混合过渡。3006、3025最后1.2秒进入源待机20，并从同帧骨架重算腰部蒙皮；渲染高度同步处理。
重力陨石3017发射后的恢复段默认半速播放。正向突进3031在冲刺开始时锁点，默认停在目标前1.5格，并沿实际路径持续判定，避免先冲过目标再拉回。

Boss 受伤使用原版逻辑，不进行原作伤害换算。
远程识别除投射物和已有行为判断外，也考虑玩家伤害来源与 Boss 的距离。
远程防御、分身追击、短暂退让、参与者、投技与技能数值由当前主配置控制。

## 2. 已冻结的运行合同

### 2.1 参与者与生命周期

- `max_active_players` 默认 4，合法范围 1-16；默认平衡只保证 1-4 人。
- 最大生命倍率始终为 `1 + health_per_extra_player × (N - 1)`，默认每名额外玩家增加 55%。
- 参与名单按每场累计唯一 UUID 计数，达到上限后不释放席位，生命只增不减。
- DORMANT Boss 由场内玩家或其归属来源首次攻击唤醒；该次攻击只登记、不伤害。
- 战斗中玩家或归属来源首次攻击只登记并扩容，本次不造成伤害或硬直。
- Boss 首次命中未登记玩家时，先批量登记同次攻击命中的合格玩家并扩容，再正常结算伤害。
- 名单满后，额外玩家仍可成为目标和受到伤害，但不能登记或伤害 Boss。
- 创造玩家默认不参与；旁观玩家始终排除。
- 死亡、断线和越界默认永久退出本场；换维度可在 100 tick 宽限内返回。
- 场内无有效参与者时完成当前动作后冻结；不允许新人接力；合法返回者恢复并清空技能冷却；超时完整重置。
- 服务器重启默认恢复 NBT 状态，但停服断线不豁免退出规则；区块卸载默认重置。
- 和平难度允许战斗；DORMANT 实体永久保留；多个逻辑场地允许重叠。

### 2.2 阈值与危险区

- 65% 转阶段默认截断本次伤害到阈值，溢出伤害丢弃。
- 25% 星陨默认截断到阈值；等待当前 `ACTIVE` 结束期间锁血免伤。
- `METEOR_SCRIPT` 总长 150 tick，0-120 tick 无敌，全程不积累硬直，第 121 tick 落地结算。
- 首次星陨后，3600 tick 冷却结束会在当前 `ACTIVE` 结束后自动再次排队。
- 进入转换、星陨或战败立即清除全部 Boss 所有危险。
- 进入眩晕时，已生成危险继续结算，尚未生成的危险取消。
- 重力重招、跳劈/冲锋和二阶段高威胁动作默认在 `ACTIVE` 期间拥有可配置霸体。

### 2.3 伤害与目标

- Boss 受伤来源默认限制为 40 格边界内玩家及其归属来源；管理员强制死亡标签例外。
- 绝对免疫伤害由 `elder_bosses:promised_consort_immune` 数据包 Tag 控制，不在 TOML 重复维护。
- Boss 技能默认可波及全部 `LivingEntity`；`elder_bosses:promised_consort_attack_immune` 中的实体类型绝对免疫，默认只包含约定之王本体。
- 非玩家实体不进入主目标选择器。
- 流血、霜冻和睡眠只识别伤害来源标签，不实现积累系统。
- 中毒/凋零实际伤害乘 0.35；流血触发伤害进入物理通道并乘 0.50；霜冻触发伤害进入魔法通道并乘 0.50；睡眠标签伤害乘 0。
- 常规技能不附加自定义击退，只保留原版伤害反应和明确脚本位移。

### 2.4 当前资产与依赖

- Boss 本体和分身已使用正式双阶段 GeckoLib geo、原创像素图集与 43 段动画，保留已有资源 ID。
- Forge 使用 GeckoLib 4.8.4 和 `mclib:20`，NeoForge 使用 GeckoLib 4.9.2。
- Forge 使用 AttributeFix 21.0.5，NeoForge 使用 AttributeFix 21.1.3。
- GeckoLib 与 AttributeFix 在 Forge 节点使用 `modImplementation`，在 NeoForge 节点使用 ModDevGradle 支持的 `implementation`；均不内嵌、不写入模组 metadata。
- 缺少 GeckoLib 时接受类加载失败；缺少 AttributeFix 时接受原版静默夹断最大生命。
- 完整指示器必须实现；技能额外使用可配置原版粒子占位，本体不显示持续轮廓。
- 重力岩块默认渲染为哭泣的黑曜石方块模型；分身共享正式骨架，以半透明金白图集及六类独立动作表现。
- 四件约定之王物品使用原创纯色临时 PNG，并加入统一 Elder Bosses 创造模式标签页。
- 当前只实装独立瞬防提示音；其他非语言音频配置保留为 reserved。

## 5. 双版本工程规则

- 1.20.1 Forge 是主实现节点，Java release 17；1.21.1 NeoForge 使用 Java release 21。
- 共享玩法代码不导入 Forge/NeoForge API。
- 注册、事件、配置、网络和客户端事件差异集中在 `platforms`。
- GeckoLib 的 `AnimatableInstanceCache` 与 `AnimatableManager` 包路径差异是 `GeoEntity` 业务类中允许的明确 Stonecutter 例外。
- Forge 使用 `SimpleChannel`，NeoForge 使用 payload/`StreamCodec`；共享包模型不得引用加载器类型。
- 手写数据包资源必须同时处理 1.20.1 复数目录和 1.21.1 单数目录。
- 新增 Java 文件后，最终构建阶段必须对两个节点使用 `--rerun-tasks`，避免 Stonecutter 生成源码缓存漏编译。

## 6. 性能预算

- 目标扫描只在重选目标或 `ACTIVE` 查询发生，不做每 tick 96 格全量扫描。
- 每次判定先用 AABB 粗筛，再执行扇形、胶囊、圆柱、环或矩形精确检查。
- 单 Boss 最多 16 个逻辑投射物、24 个逻辑光柱、4 个分身表现实体和 32 个逻辑指示器。
- 客户端全局最多 64 个指示器；圆弧分段受配置限制并按距离降级。
- 危险区、投射物和参与者容器使用稳定 ID 与有界集合；按动作结束、状态转换、实体移除和过期 tick 主动清理。
- 常态自定义同步目标低于 2 KB/s/玩家；静态时间轴参数不逐帧发送。

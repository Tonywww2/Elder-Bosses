## 3. 关键辨析

| 容易误读的说法 | 核对结果 | 本文处理 |
| --- | --- | --- |
| `125 / 80` 是两阶段韧性 | 原始 Boss 模板字段是防御 125、韧性 80，两阶段相同 | 只保留为原作事实；Minecraft 实现改用实际生命损失按比例累计的硬直值 |
| 第二阶段是同一血条半血转阶段 | 第一阶段归零才转换；第二阶段独立生命约为第一阶段 80% | 实现两条生命池，第二阶段从自身上限 80% 开始 |
| 水鸟乱舞只有三刀或四刀 | Boss 页按四轮追击描述；玩家战技页为三组输入、十次斩击加剑风 | Minecraft 版采用三轮移动、十个视觉斩击与每轮命中上限 |
| 联机中马莲尼亚会隔空回血 | 1.04.1 明确修复联机环境回血不正确 | 只有服务端确认接触或格挡时恢复，延迟包不能凭空回血 |
| 她应免疫猩红腐败 | 原作数据是极高抗性而非免疫 | 默认积累倍率 0.10，可由配置改为完全免疫 |
| 第二阶段所有剑击都有额外腐败伤害 | 原作描述为许多攻击施加腐败状态 | 只增加积累，不暗加未列出的生命伤害 |
| 开花三次意味着本战必有第三阶段 | 物品叙事称第三次会成为真正女神，但原作 Boss 战只有两阶段 | 不添加隐藏阶段；留作后续独立 Boss 或剧情钩子 |

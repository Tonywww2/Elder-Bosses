# Boss 技能指示器设计规范

> 适用 Boss：`elder_bosses:malenia`、`elder_bosses:promised_consort`  
> 目标平台：Forge 1.20.1 与 NeoForge 1.21.1  
> 配置来源：唯一 common 配置 `config/elder_bosses-common.toml`

## 1. 设计目标

技能指示器负责在攻击生效前表达服务端真实判定的形状、方向、锁定状态和生效顺序。它不能替代 Boss 姿势、武器轨迹、音效或瞬间防御红光，也不能制造服务端不存在的安全区。指示器映射由程序固定，不引入自定义招式数据包类型，也不引入自定义指示器数据包类型。

1. 每个伤害段的指示器由服务端动作状态生成，客户端不预测技能选择或命中结果。
2. 指示器几何与服务端判定使用同一组半径、长度、角度、宽度和锁点快照。
3. 地面填充受地形和实体遮挡，边框以较低透明度隔遮挡可见。
4. 颜色只表达伤害语汇，形状、线型、脉冲方向和分段数量承担主要可读性。
5. `indicators.opacity` 是唯一全局透明度基准，两位 Boss 不设置各自的透明度选项。
6. 指示器在最低粒子设置下仍保留；关闭粒子不等于关闭玩法提示。

## 2. 从 MC Dev Skill 采用的实现原则

- Forge 1.20.1 世界空间几何在 `RenderLevelStageEvent.AFTER_TRANSLUCENT_BLOCKS` 阶段绘制：沿用事件 `PoseStack`，只执行一次 `-camera` 平移，再提交绝对世界坐标顶点。
- 坐标阶段与遮挡策略分离。不能为了“更晚绘制”随意切换到矩阵语义不同的阶段，否则标记会随相机漂移、倾斜或异常放大。
- 透视边框使用独立 `RenderType` 和独立批次；Forge 1.20.1 调用 `RenderSystem.disableDepthTest()` 必须包围实际 `endBatch`，并在 `finally` 中调用 `RenderSystem.enableDepthTest()` 恢复深度状态，不能只包围顶点写入。
- 客户端视觉读取一份由服务端包更新的静态状态；包处理切回客户端主线程。战斗结束、实体移除、维度切换和断线时必须 `clear()`，防止残留指示器。
- 平滑动画使用 `action_tick + partialTick`；服务端仍以整数 tick 决定锁定和伤害。视觉插值不得回写服务端状态。
- 单纯放置 shader 文件不会产生效果。若后续使用自定义 core shader，必须有客户端注册和实际渲染调用；当前基础方案可用世界空间顶点、透明 `RenderType` 和 SDF 纹理实现。
- NeoForge 1.21.1 的具体事件签名由 `platforms` 客户端适配层隔离；它必须保持与 1.20.1 相同的相机相对坐标、双 pass 深度语义和状态清理行为。未经目标依赖核验，不在共享规格中写死某个未验证的 1.21.1 API 签名。

## 3. 单一 common 配置

运行时只注册一个 `ModConfig.Type.COMMON`，文件名固定为 `config/elder_bosses-common.toml`。全局指示器配置只出现一次：

```toml
[indicators]
enabled = true
opacity = 0.60
occluded_outline_opacity_multiplier = 0.35
render_distance = 96.0
surface_offset = 0.02
max_active_indicators = 64
max_segments_per_shape = 96
```

有效透明度按下式计算：

`最终透明度 = clamp(opacity × 图层倍率 × 时间轴倍率, 0, 1)`

| 图层 | 固定图层倍率 | 说明 |
| --- | ---: | --- |
| 地面填充 | 0.45 | 受深度测试遮挡，不压过方块纹理 |
| 可见边框 | 1.00 | 受深度测试，完整显示真实边界 |
| 遮挡边框 | `occluded_outline_opacity_multiplier` | 不受深度测试，只绘制边框，不绘制填充 |
| 锁定脉冲 | 1.00 | 只持续 2 tick，强调停止追踪的时刻 |

`opacity` 合法范围为 0.10-1.00，默认 0.60；低于 0.10 会导致关键提示不可辨，因此启动时回退到 0.10。该值是 common 配置中的本地视觉项，不参与命中计算。服务端仍同步指示器状态，但不根据客户端透明度改变战斗行为。

## 4. 渲染层与遮挡

每个地面指示器最多使用三个绘制层：

1. **填充层**：贴合可行走表面，开启深度测试；填充遵循深度遮挡，会被方块、Boss 和其他实体遮挡。
2. **可见边框层**：同样开启深度测试，绘制实线外缘、方向缺口和分段刻度。
3. **遮挡边框层**：只重复外缘线，不绘制内部填充；在实际 flush 时关闭深度测试，透明度较低，结束后立即恢复。

当边框无遮挡时，遮挡边框层与可见边框层会叠加。为避免可见区域过亮，客户端将可见边框 alpha 预乘为 `opacity × (1 - occluded_multiplier)`，遮挡边框 alpha 为 `opacity × occluded_multiplier`；无遮挡区域合计仍约等于 `opacity`。

以下内容禁止透视显示：指示器填充、腐败/血焰持续区域内部纹理、分身实体、Boss 模型轮廓和命中火花。只有危险边界、路径中心线和锁点十字可以使用遮挡边框层。

## 5. 通用形状语法

| 形状 ID | 表现 | 对应判定 |
| --- | --- | --- |
| `SECTOR` | 扇形填充、弧形外边和朝向中心线 | 横斩、踢击 |
| `CAPSULE` | 两端半圆的直线走廊、末端箭头 | 突刺、直线冲锋 |
| `CIRCLE` | 实心淡填充、完整圆边、中心十字 | 下砸、爆发、落点 |
| `ANNULUS` | 内外双边框与中间环带 | 扩张环、剑风、旋风 |
| `RECTANGLE` | 前向矩形、远端粗边 | 地裂、踩地 |
| `PATH` | 带宽曲线与移动方向箭头 | 跑斩、水鸟、侧闪 |
| `SEQUENCE` | 多个带编号刻线的形状按时间点亮 | 连段、幻影、陨石 |
| `ZONE` | 固定边界、内部低频纹理和剩余时间收缩环 | 腐败花域、血焰裂痕 |

- 虚线表示仍在追踪或尚未锁定；锁定时播放一次从虚线到实线的 2 tick 脉冲，之后世界坐标不得再变化。
- 外缘对应服务端判定边界，视觉误差目标不超过 0.10 格。装饰光晕可以越界，但必须比主边框低至少 50% alpha。
- 地表采样间隔不大于 0.25 格；指示器抬高 `surface_offset` 防止 Z-fighting。相邻采样高差超过 1 格时断开填充，只保留投影边框，避免沿墙面拉伸。
- 指示器不能绘制到竞技场逻辑边界之外；路径被墙体裁剪或 Boss 改为穿墙时，客户端使用服务端同步的最终路径，不自行延伸。

## 6. 时间轴状态

| 状态 | 视觉规则 |
| --- | --- |
| `TRACKING` | 虚线边框，位置可由服务端新快照更新；填充为目标透明度的 60% |
| `LOCKED` | 边框转实线，中心向外脉冲一次；从此不再移动 |
| `IMMINENT` | 生效前最后 4 tick，外缘每 2 tick 亮灭一次；不改变面积 |
| `ACTIVE` | 边框短暂变白或亮金，填充快速向边缘收缩；服务端开始判定 |
| `PERSISTENT` | 固定区域显示边界和剩余时间收缩环，不重复播放命中闪光 |
| `EXPIRED` | 3 tick 内淡出并从客户端状态表移除 |

瞬间防御红色武器轮廓属于另一系统，不把地面指示器整体染红。若某攻击可瞬间防御，地面形状仍使用原伤害语汇，只有 Boss 武器或攻击方向出现 `#FF2020` 三段脉冲。

## 8. 约定之王技能指示器

当前 Boss 本体使用 GeckoLib 空模型且不持续显示碰撞箱或定位环，因此全部伤害范围、锁点和进攻方向指示器必须按本节完整实现。瞬防提示当前绘制为红色攻击方向三段脉冲；正式模型到位后再改为对应剑刃骨骼轮廓。原版粒子占位由服务端 `[promised_consort.visuals]` 的总开关与质量档控制，但关闭占位粒子不能关闭本节玩法指示器。

## 9. 服务端同步合同

服务端按活动攻击段同步以下最小状态，不逐帧发送顶点：

| 字段 | 用途 |
| --- | --- |
| `boss_entity_id` | 关联指示器与 Boss 生命周期 |
| `indicator_id` | 同一动作内的稳定子段 ID，用于更新和移除 |
| `shape_type` | 程序固定的七种形状之一 |
| `origin` / `yaw` | 世界坐标原点与朝向 |
| `dimensions` | 半径、长度、宽度、角度等当前配置快照 |
| `start_tick` / `lock_tick` / `active_tick` / `end_tick` | 时间轴和锁定状态 |
| `path_points` | 仅曲线路径需要；由服务端碰撞裁剪后的有限采样点 |
| `style_role` | 物理、重力、血焰、圣光、腐败、无伤害位移 |

形状映射和技能段列表由 Java 枚举固定，不从 TOML、数据包或客户端包读取。客户端只对相邻服务器快照插值，不外推锁点。新玩家进入追踪范围时接收当前活动指示器全量快照；战斗结束、Boss 移除、玩家换维度或断线时清空对应状态。

## 10. 性能与降级

- 单 Boss 同时最多 32 个逻辑指示器；全客户端最多 64 个，超过时优先保留更早生效和更靠近本地玩家的项目。
- 圆与扇形每个最多 96 段；32 格外降到 48 段。降低几何精度不能改变逻辑半径。
- 批量按材质、深度策略和颜色角色提交，不为每个指示器单独 flush。
- 低画质首先关闭装饰纹理、次级方向箭头和内部噪声，保留填充、真实边框、锁点脉冲及遮挡边框。
- 若自定义 shader 编译失败，回退到顶点色半透明几何；不能完全隐藏指示器。

## 11. 验收

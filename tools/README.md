# 资源与开发工具

运行资源位于 `src/main/resources`；本目录保存当前可编辑源文件、生成工具和现有专项检查。

- [约定之王](consort/README.md)：原作解包、模型绑定和当前资源生成。
- [腐败女神](malenia/README.md)：当前 Blockbench 模型、动画和材质。
- [物品美术](items/README.md)：当前物品图标源文件。
- `shared/config`：配置规范、双语展示与配置核对。
- `shared/curios_gametest`：Curios 集成检查。

生成的预览、交付清单和验证报告写入 `build`。历史版本、旧导出副本和完成后的阶段记录不留在工具目录。

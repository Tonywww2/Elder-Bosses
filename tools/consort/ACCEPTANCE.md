# 约定之王当前验收

## 命令

```text
/elderbosses test promised_consort source_animation 3010 1
/elderbosses test promised_consort source_act 20 2
/elderbosses test promised_consort source_act 17 2
/elderbosses test promised_consort source_act 21 2
```

`source_animation` 只预览姿态；`source_act` 执行实际动作链和伤害，并在 60 秒后清理。

- 腰部连续、双刀握持、身体升降、落地和连段收尾没有跳变。

## 双层光柱验收

- 剑击、圣光爆发、光环、米凯拉之光、分身、星陨和二阶段转场均为金色外层＋浅白内层方形光柱，没有旧细光线、圣光光点或扇形神门光。
- 出现时50%不透明；先慢速、后快速收窄和变透明，高度保持不变且为配置高度的1.5倍。地面光圈只在光柱消失后出现，以6%不透明度用配置时长的一半消失。
- 移动圣光沿原弹丸路径产生间隔光柱；伤害判定与时序仍按技能配置执行。
- 主配置 `promised_consort.skills.visuals.holy_columns` 内的各预设可独立调节宽、高、两段衰减时间、光圈半径和时长；中英描述简洁。不得另建配置文件。
- 关闭特效、切换世界、Boss移除后清除缓存；同一来源不会逐帧重复生成光柱。普通灰白刀光和魅惑透明符号保持各自用途。

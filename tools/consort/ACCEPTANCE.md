# 约定之王当前验收

## 命令

```text
/elderbosses test promised_consort source_animation 3010 1
/elderbosses test promised_consort source_act 20 2
/elderbosses test promised_consort source_act 17 2
/elderbosses test promised_consort source_act 21 2
```

`source_animation` 只预览姿态；`source_act` 执行实际动作链和伤害，并在 60 秒后清理。

## 游戏内项目

- 祭坛在神门前高坡召唤休眠 Boss；休眠、开场和战斗始终使用当前模型。
- 激活后从当前站位开场，没有预先传送升空；二阶段朝神门行走，米凯拉出现后转向场心，两句台词正常。
- 腰部连续、双刀握持、身体升降、落地和连段收尾没有跳变。
- 米凯拉头顶覆盖完整，34束长发长短错落，弯折处没有明显断缝；下颌与闭眼五官协调，四手在待机和投技时指节连续；待机、投技和二阶段转场中腰腹与上衣、下袍衔接完整。
- 普通刀光为完整灰白色宽轨迹；地面预警显示各段大致命中范围。
- 简单范围与轨迹模式都能命中；同段接触免疫默认0.5秒，进入下一段提前清除。双刀及派生弹体不绕过免疫。
- 分身锁定与落点正常；远程防御可按当前规则退出。
- 正向突进在目标前1.5格停靠，不冲过后拉回；两种命中模式均能击中冲刺路径上的玩家。
- 重力陨石空中发射后的恢复段半速播放，源时间6至7.5秒连续下降，触地后再结束动作；大荒星陨起手向上光柱起点降低0.6格；投技扩大后的边缘可捕获，范围外不捕获。
- 总血量65%进入二阶段，85%首次星陨锁血并立即无敌，等待当前招式结束后升空，落点固定场心。当前run与默认预设为1200tick，即60秒；冷却从收招完成后计时。
- 开启重新参战时，玩家死亡、复活和重新进入场地后可以继续战斗；当前run预设默认关闭此选项。
- 侧向突进、圣光爆发、陨石最终俯冲和光环的效果与命中位置一致；光环高度可配。
- 米凯拉之光默认无敌，关闭主配置选项后可以受伤。
- 技能播报随主配置开启/关闭；击败掉落服从当前数据包战利品表。
- 胜利音效较响、较慢且低沉，无破音。
- 不平坦地面、多人、抓取、实体保存恢复和场地重置正常。

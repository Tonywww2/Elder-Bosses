# Haligtree chamber R2

The arena is authored offline and exported as eighteen fixed structure pieces and
one metadata root for each supported Minecraft version. Runtime Java loads the NBT;
it does not regenerate roots, terrain or material noise. See the
[Chinese build and command guide](../../../docs/arenas/malenia-arena.md).

`build_arena.py` owns the layout, custom block models and three flower-clump variants.
Each clump has 7, 9 or 11 plants, with four block rotations and varied plant heights,
widths and angles. `ExportTextures.java` exports four native 16x16 tiles from the
archived imagegen originals; see [prompts and provenance](textures/PROMPTS.md).
`manifest.json`
records dimensions, anchors, block counts and exact output hashes. Rerunning the
exporter is deterministic and overwrites only this arena's resources.

```powershell
python tools/malenia/arena/build_arena.py
java tools/malenia/arena/ExportTextures.java
node tools/consort/tests/run_attack_plan_check.js ../../malenia/tests/ArenaAssetCheck.java
node tools/consort/tests/run_attack_plan_check.js ../../malenia/tests/ArenaVisualCheck.java
.\gradlew.bat -PmaleniaSurfaceCheck -I tools/malenia/arena/gametest.init.gradle :1.20.1-forge:runMaleniaArenaTest --offline
.\gradlew.bat :1.20.1-forge:build :1.21.1-neoforge:build --offline
```

Java 25 is used to launch Gradle and the standalone checks. The standalone runner
uses the existing exported Forge runtime classpath. GameTest adds test sources and
a one-block fixture only for that invocation, under `build/malenia-arena-gametest`;
normal release builds must run afterwards without the init script. Pass
`-PmaleniaWorldgenCheck` for the separate `build/malenia-worldgen-gametest` world.
R2 uses `-PmaleniaSurfaceCheck` and `build/malenia-surface-gametest` so older saved
template snapshots do not mask the new pool. Do not reuse the R1 test world for R2.
The fixture includes noise-generated dimensions with fixed dark-forest and plains
biomes to test natural structure placement and biome rejection.

The four preview frames use the exported voxel composition and shipped textures
with illustrative lighting. A fifth close-up reads the actual three flower model
JSON files. They show entrance, water/flowers, reverse view and cutaway. They are
not screenshots from a client world. Only preview
lighting and cutaway clipping are synthesized; they are not exported into NBT.

The natural-generation variant uses `worldgen_root` and nineteen fixed pieces,
reusing fourteen original pieces and replacing four stairwell pieces. One extra
15×27×17 piece reaches the surface. Eight three-wide return flights connect the
vestibule to `surface_entry=(3,58,46)`. `worldgen_manifest.json` records the added
resource hashes. No geometry is generated by Java at runtime.

Worldgen defaults to dark forest, random spread spacing 48 / separation 16,
frequency 0.5, with dry supported terrain, roof cover and entrance slope checks.
See the Chinese guide for datapack paths and `/locate`. Natural pieces preserve
their template snapshots in chunk saves. Operator undo applies only to manual
placements; it is separate from natural structure saves.

Sneak-use the prayer tile below `fog_gate` with a main-hand rune fragment to summon
and bind Malenia. `malenia_offerings` is the overridable item tag. Existing R1
structures accept the original polished-andesite tile at that exact anchor.
Copied altar blocks cannot summon. The tile is a full-height block using the new
prayer-stone top; it does not alter the walkway collision surface.

The pool contains 273 bottom `haligtree_silt_slab` blocks with `waterlogged=true`.
The collision floor is half a block below the shore, backed by a full foundation
and full-block banks. The water is a real vanilla fluid with biome tint. Ground
navigation recognizes solid slab support; landing projection uses its actual
0.5-block collision height. The template loader allows only contained, bottom,
waterlogged silt slabs and rejects arbitrary physical fluids. Manual placement
continues to reject existing fluids in the destination before overwriting it.

`haligtree_shallow_water` remains registered for old world saves but is absent
from new templates and the creative tab. Existing chambers keep their saved
geometry; their shared flower models and textures update immediately. Build a
new chamber or explore new chunks to obtain the R2 pool.

Dimension-local saved data records one boss UUID per origin. Chunk unload keeps
ownership; destructive removal releases it. The bound entity persists anchors
and arena settings, rejects duplicate owners, constrains movement/targeting,
projects aerial attack landings onto the chamber floor, and resets to its spawn
after the configured empty-arena grace period. Unload resets the fight by default.
Manual undo rejects occupied chambers. Battle doors, encounter damage logging,
block restoration and a custom sky are not implemented.
